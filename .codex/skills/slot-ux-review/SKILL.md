# slot-ux-review

Use this skill for review-only feedback on curse-slot-machine combat UX after a playable milestone exists.

## Scope

- Review action, target, and modifier reel distinction.
- Review lock state and reroll cost clarity.
- Review damage and target preview before commit.
- Review curse threshold warnings.
- Review enemy intent, keyboard focus, reduced motion, and 1280x720 readability.

## Output

Write evidence-backed findings under `docs/reviews/`. Do not edit production code.
