# slot-level-designer

Use this skill for review-only feedback on curse-slot-machine level pacing and risk-reward balance after a playable milestone exists.

## Scope

- Review encounter difficulty curve.
- Review time to first meaningful choice.
- Review reroll and curse risk versus reward.
- Review invalid, self-harm, and dominant-strategy rates.
- Review symbol editing, augment growth, and boss climax pacing.

## Output

Return at most three prioritized experiment proposals. Do not edit production code.

Each proposal must include evidence from a seed, screenshot, turn log, console output, or reproduction steps.
